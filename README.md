# Amazon E Commerce Sales Performance Analysis | Python | Tableau

## Project Overview
Project ini berfokus pada analisis performa penjualan <i>e-commerce</i> dengan mengeksplorasi tren penjualan, kategori produk, wilayah, fulfillment, dan status order. Analisis dilakukan untuk mengidentifikasi pola dan temuan utama yang dapat memberikan <i>insight</i> mengenai performa penjualan dan karakteristik transaksi.

<b> Business Questions</b>
- Bagaimana tren penjualan dari waktu ke waktu?
- Kategori produk mana yang memberikan kontribusi penjualan terbesar?
- Wilayah mana yang memiliki kontribusi penjualan terbesar?
- Bagaimana performa penjualan berdasarkan fulfillment?
- Bagaimana distribusi order berdasarkan status?
- Bagaimana quantity terjual berdasarkan kategori?

Analisis dilakukan menggunakan data transaksi Amazon e-commerce selama trimester kedua tahun 2022. Python digunakan untuk proses data preparation, data cleaning, dan Exploratory Data Analysis (EDA), sedangkan Tableau digunakan untuk membuat visualisasi interaktif dan menyajikan hasil analisis.
